# 🎣 방치 낚시

가만히 둬도 물고기가 잡히는 방치형 낚시 웹게임이에요.

## 실행

`index.html`을 브라우저로 열거나, GitHub Pages 주소에서 플레이할 수 있어요.

## 진행 상황

- [x] 1단계: 자동 낚시 + 골드
- [x] 2단계: 업그레이드 상점
- [x] 3단계: 저장
- [x] 4단계: 오프라인 보상 (최대 12시간)
- [x] 5단계: 물고기 종류 / 도감 / 낚시터 (호수, 바다, 심해 · 물고기 12종)
- [x] 꾸미기: 낚시 장면, 튀어 오르는 물고기, 낚시터별 배경, 전설/희귀 연출
- [x] 밸런스 조정 (바다 약 15분, 심해 약 2시간), 최대 구매 버튼, 만/억 단위 표시
- [x] 환생 시스템: 진주, 진주 상점(황금 그물, 행운의 부적, 긴 휴가), 도감 보너스
- [x] 무한의 탑: 스타포스 캐치 방식 직접 낚시, 하루 3회, 최고 층당 수입 +2%, 보스 층 체크포인트, 보스 폭주(보호막 원 타이밍)
- [x] 탑 난이도 완화 + 진주 상점 탑 강화(매의 눈, 묵직한 추, 튼튼한 낚싯줄, 반사 신경)
- [x] 픽셀아트 디자인: 스프라이트(물고기, 낚시꾼 동작, 물, UI 부품) 적용, 물속에서 헤엄치는 물고기
